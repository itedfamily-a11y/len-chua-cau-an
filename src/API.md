# "Lên Chùa Cầu An" — module contract (read this first)

The game is ONE `index.html`, built by `node build.js` from `src/shell.html` + every `src/NN-*.js` file
concatenated (sorted by name) into a single `<script type="module">` (`build.js` normalises CRLF to LF in `shell.html` and in every module with `.replace(/\r\n/g, '\n')` because a few sources are still CRLF, `.trim()`s each module, and takes `ONLY=00,05,…` for a subset build and `OUT=file` for another output name; it injects the modules at the `//@@MODULES@@` marker of the shell). Three.js r160 is imported once in
`00-core.js` (`import * as THREE from 'three'`). Every module file must contain exactly ONE top-level
declaration: `function installXxx(G) { ... }` — no imports, no other top-level code/const/let (they would collide).
Boot order (`99-boot.js`): buildWorld → buildWorld2 → buildWorld2Geo → buildChinhDien (18; it calls buildBanTho from 18-ban-tho.js for the altar, which calls banThoAtlas from 18-ban-tho-tranh.js — hoisted function declarations of the one module) → buildCungDinh (19) → buildDienPhu → installQuanAmQuet (17-quan-am-quet.js, step "tượng Quan Âm (bản quét 3D)") → installDiaTangQuet (17-dia-tang-quet.js, step "tượng Địa Tạng (mô hình 3D)") → buildVuonSau (19-vuon-sau.js, step "vườn sau chùa") → installNuocCa (19-nuoc-ca.js, step "mặt nước hồ sen & đàn cá") → installSenHo (19-sen-ho.js, step "sen trong hồ (mô hình 3D)") → installQuanAmHo (19-quan-am-ho.js, step "tượng Quan Âm giữa hồ (mô hình 3D)") → installDenDa (19-den-da.js, step "đèn đá vườn sau (mô hình 3D)") → buildDecorInside → buildGateSign → buildScenery → installCayMoHinh (13-cay-mo-hinh.js, step "cây mô hình 3D (sồi, thông)") → installFx → installHauKy (07-hau-ky.js, step "hậu kỳ") → installPlayer → installAudio → installMusic → installKinhVan (21) → installCrowd →
installActivitiesA → installActivitiesB → installHoaDangSen (41-hoa-dang-sen.js, step 'đèn hoa đăng (hoa sen mô hình 3D)') → installNgoiTungKinh (45) → installActivitiesC → installDiChuaChung (22, step 'đi chùa chung') → installLoiMoi (23, 'lời mời vào nhóm') → installGiongNoi (24, 'giọng nói trong nhóm') → installGiongNoiUI (25, 'giao diện giọng nói', last) → G.start(). - All UI text Vietnamese (with diacritics). Gentle, respectful tone: no jokes about the Buddha, no monsters,
  no win/lose, no harsh ranking. Never claim prayers are guaranteed to come true. Never mention money/donations.
- User text (names, prayers) is ALWAYS inserted with `textContent` / canvas fillText — never innerHTML.
- Per-frame code (`G.onUpdate`) must not allocate: reuse module-level Vector3/Matrix4/Object3D temps.

- Coordinates: meters, y up. Character "yaw": forward = (sin yaw, 0, cos yaw); facing north (−z) is yaw = π.
  `G.util.yawTo(x0,z0,x1,z1)` gives the yaw that faces from point 0 to point 1.
